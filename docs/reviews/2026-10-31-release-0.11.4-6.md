## 1. 本版内容

- **网络学堂 403 按会话失效自愈**（`14114ea1`，覆盖 `5505aee7`/`1301ea13`/`7708527e`）。
  学习域对「无会话或陈旧 `_csrf`」回 403，旧代码把它当裸错误：不重登、不换凭据，用户点「重试」
  撞的仍是同一份死会话。现在 401/403 一并进入重建链，重建后用新客户端重放；并发里晚到的旧
  请求 403 不会作废别人刚重建好的新凭据；而取凭据页上的 403 仍归为服务失败，交给启动链静默重登。
  门户返回的错误 JSON 同样判为会话过期，静默重登不再空转。
- **基线换到上游 `38a3aa69`**：NextTHULearn 插件的课程看板与品牌资产、官方未读数与课表数据
  （`dac5c5fe`/`c000eb60`/`47aba55c`）。分叉补丁按 `-U0` 逐行比对过，增删行与改写前完全一致。
- 分叉侧延续进版：全天事件横幅行（方案 A）、自定义日程重复规则、悬浮圆钮拖动与手机底部 Sheet、
  系统日历差异同步、CLI 运行时可分离安装、托盘/悬浮球保活、Windows 私有存储适配。
- 安装包继续走「瘦客户端 + 可选 CLI 包」：Windows exe 与 macOS dmg 不含 Node 运行时；桌面端
  「安装 CLI」按应用版本从本仓 Release 取 `OneTHU-CLI_0.11.4-6_*.zip`。本版 macOS CLI 包是
  原生 `darwin_arm64`（0.11.4-5 是 x64 交叉打包）。
