# 分叉 0.11.4-3 发布记录：基线换到上游 0.11.4-fix-1

> 最后更新：2026-10-27 20:32

日期：2026-10-27。基线：`main` / `d4d246c6`（`fork-0.11.4-3` tag 指向该提交）。
本版主体是 [rebase 到上游 0.11.4-fix-1](2026-10-27-fork-rebase-0.11.4-fix-1.md)，
外加在 CI 上暴露出来的一个 Windows 私有存储缺陷。

## 1. 本版内容

- 上游 0.11.4-fix-1：登录在驻留会话恢复期间不再被锁死（`AUTH_IN_PROGRESS` 不再永久拒绝）、
  daemon 启动失败会把真实错误码写进 `daemon-startup.log`、私有目录 ACL 改为显式 .NET 写入
  并带 15s 超时与失败阶段标记、GUI 在 CLI 采纳会话后恢复匹配的凭据。
- 分叉保留：`cli_daemon` 的凭据文件属主接受 `BUILTIN\Administrators`（上游仍是 `EqualSid`）、
  系统日历同步轨迹的 `sync_trace` 权限（上游没动该插件）、托盘/悬浮球保活、日历差异同步、
  自定义日程重复规则。
- **新增修复**：`packages/sdk/src/notifications/storage.mjs` 的 `whoami.exe` / `icacls.exe`
  改为从 `%SystemRoot%\System32` 解析绝对路径。GitHub 的 Windows runner 上 PATH 里 Git 自带
  coreutils 的 `whoami.exe` 排在系统程序前面，`whoami.exe /user /fo csv /nh` 直接报
  `whoami: extra operand '/user'`，通知存储的私有目录初始化失败，整个调用被 `sdkError()`
  压成兜底码 `CLI_OPERATION_FAILED`。从 Git Bash 里跑 CLI 的用户会踩同一条。
- 测试：`packages/cli/test/startup-recovery.test.mjs` 的预算放宽（客户端 2s→15s、等
  probe-held 3s→15s、启动 10s→30s、每例 15s→60s）。断言与产品行为未改。

## 5. 已知边界

- 分叉原先的 `icacls` 版 `privateMode()` 已按「上游已解决就丢补丁」删除，改用上游实现。
- macOS 由 `macos-latest`（arm64）原生构建，未在 Apple Silicon 真机安装验证。
- `apps/desktop/src-tauri/gen/schemas/{android,macOS}-schema.json` 要等对应平台的构建才会带上
  `allow-sync-trace`；Windows/desktop 两份已更新。
- 上游 `startup-recovery` 测试在 Windows 上依赖 PATH 顺序；本版的产品侧修复正是消除这一点，
  测试预算的放宽只是让慢机器不再误报超时。
