# 系统日历镜像对重复日程平铺展开，不写原生 RRULE

0.11.3-4 的批量删除事故（鸿蒙兼容层上事务回滚、进程崩溃）之后，CalendarMirror 以差异驱动不变量运行：稳态零写入、删除只按单条 `_id`、匹配键是逐场内容签名。原生 RRULE 会让一条日历记录携带规则与例外集，provider 回读与内容签名的一致性无法在目标机型上保证。因此重复日程（无论编辑器创作还是云侧导入）在滚动同步窗口内展开为逐场单事件写入系统日历，原生侧不感知「系列」。

## Consequences

- 一条永不截止的每周系列在 18 个月窗口内约占 78 场；窗口滚动使系列边缘按周期增删（内容变化才触发写入，稳态不变量不受影响）。
- 系统日历应用内的原生重复交互（改一场即改整系列等）不适用；系列级修改经由本应用编辑器完成，整系列语义见根目录 [CONTEXT.md](../../CONTEXT.md)。
- macOS EventKit 路径同为平铺写入，与 Android 保持同一语义。
